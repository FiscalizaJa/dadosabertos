# ✨ FiscalizaJá + Google Gemini
Gemini é uma família de modelos desenvolvida pela Google, com foco maior em compreensão de texto.
Recentemente, a Google diminuiu os preços da API do Gemini para quase 80%, o tornando uma excelente opção para projetos com orçamento baixo, como o FiscalizaJá. Por isso, Gemini é o modelo principal utilizado pelo FiscalizaJá.
