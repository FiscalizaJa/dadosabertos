# 🧐 FiscalizaJá Open Questions
Esse serviço é um complemento aos dados abertos do Senado e Câmara dos Deputados.

Por este, cidadãos podem escrever questionamentos em despesas específicas de todas as despesas cobertas pelo FiscalizaJá, visando informar possíveis irregularidades, fazer protestos (como um gasto excessivo, entre outros).

## 📌 Informações importantes sobre o comportamento de um questionamento
- Mais de um questionamento por despesa pode ser feito, porém somente um por usuário.
- Um questionamento pode receber votos indicando se é relevante ou não, uma vez que receber muitos votos negativos, é removido automaticamente pelo sistema.
